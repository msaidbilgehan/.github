# .github

Default [community health files](https://docs.github.com/en/communities/setting-up-your-project-for-healthy-contributions/creating-a-default-community-health-file) for [@msaidbilgehan](https://github.com/msaidbilgehan)'s repositories.

[`.github/FUNDING.yml`](.github/FUNDING.yml) sets the **Sponsor** button (GitHub Sponsors and Buy Me a Coffee) of every repository that has no `FUNDING.yml` of its own. The button shows only in repositories where *Settings → General → Features → Sponsorships* is turned on.
